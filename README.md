# Generic File Upload UI
This is a simple File Upload UI to upload your file into the server and to view what are the files that are found in the server

# Local set up
1. Create and activate Virtual Environment
$python -m venv venv
$venv\Script\activate
2. Install all python packages
$python -m pip install -r requirements.txt
3. Start local server
python main.py run --debug
4. Open the browser and go to the local website
http://127.0.0.1:5000/
