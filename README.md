# Self Service Portal
This repository serves as a place to show case my work in creating a self service portal for users to get their internet access from start to the end. It is purely a mock up exercies. 

It is currently a work in progress. If you do have any opinions or comments regarding this, do let me know. 

Thank you. 

# Frontend

## How to create frontend local setup
- Install nodejs and npm
- install desired React version
npm install react@18 react-dom@18
npm create vite@5
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p

# Backend

## How to create backend local setup
- Install python version 3.13
- create virtual environment
- Install from requirements.txt
