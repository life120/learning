Node Package Manager (npm) is a package manager that comes bundled with Node.js.
It helps developers to easily install, share, and manage reusable JavaScript code (packages/modules) in their projects.
npm hosts a registry of open-source JavaScript libraries and tools.


## How to check if npm is installed?
$npm -v

## How to install a specific version of npm?
Open powershell in Admin Mode
Check that NPM is already installed
Ensure that [[Chocolatey]] is installed and upgraded to the latest version.
$npm -v
$npm install npm@10.8.2
