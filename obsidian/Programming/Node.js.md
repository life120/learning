Node.js is a JavaScript runtime built on Chrome's V8 engine.
It allows developers to run JavaScript on the server side, enabling backend development and full-stack applications.
Node.js provides an environment for executing JavaScript code outside the browser. 

How to check NodeJS is installed?
- Open Powershell
- $node -v
- It should show the NodeJS version in the command prompt

How to upgrade Node.js
https://nodejs.org/en/download/package-manager
Open powershell as admin
$choco install nodejs-lts --version="<specify exact version number here>"
e.g. choco install nodejs-lts --version="20.18.0"
It should update the npm version to the required version.
