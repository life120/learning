A slug is the part of the URL that identified a particular page on a website in an easy-to-read form. It is part of the URL that explains the page's content.

e.g. https://yoast.com/<slug>
e.g. https://yoast.com/how-to-create-websites-in-django

Why is it important to create a good URL slug?
- It can positively affect the SEO by including the proper keywords
- Keyphrases makes it easier for people to understand what the page is about. This will be better than finding a page that does not a proper URL indication.

How to create a good URL slug?
- Include keyphrase in the slug
- Think about the function words e.g. 'a', 'the', 'and'
- focus on the words that matters
- keep it short and descriptive
- use lower-case only
- make it permanent because changing it will be very bad for the SEO
