## Git Commit Message
#### Conventional Commits
The conventional commit message style is another way you can level up your commit messages. The conventional commits structure involves starting your commit message with a specified commit type. Commit types include:

Feat - Feature
Fix - Bug fixes
Docs - changes to the documentation like README
Style - style or formatting change
Perf - improves code performance
Test - test a feature

e.g.
Summary:
Docs: Fixed type on in-from-the-depths.md
Description:
Closes ticket #54321

#### Git Commit Frequently
This will ensure that the commit summary and description can be made short

#### How to create the git message in CLI
$git commit -m summary -m Description

#### How to amend the most recent git commit message
$git commit --amend -m summary -m description
