### **Updated Breakdown of the Request Access Page (Wireframe)**  

The **Request Access Page** dynamically adjusts its form based on whether the user is requesting access for a **User** or a **Server**.

---

### **1. Sidebar Navigation**
- Contains links to key pages:
  - **Home**
  - **Request Access**
  - **Approval Status**
  - **Help/FAQs**
  - **Admin Dashboard**
- **Portal Logo** at the top.

---

### **2. Header Section**
- **Title:** "Request Access"
- **Brief Description:** Explains the purpose of the page and guides users to select whether they are requesting access for a **User** or a **Server**.

---

### **3. Access Request Selection**
- **Dropdown Menu:** "Apply for"  
  - Options: **User** or **Server**
  - When a user selects an option, the corresponding form is displayed dynamically.

---

### **4. User Access Request Form (Shown when "User" is selected)**
- **Title:** "User Access Request"
- **Fields:**
  - **Your Name** (Pre-filled or entered manually)
  - **Your Email** (Pre-filled or entered manually)
  - **Requested URL** (Textbox for entering the URL)
  - **Access Justification** (Textarea for explaining the request)
  - **Submit Button:** "Submit User Request"

---

### **5. Server Access Request Form (Shown when "Server" is selected)**
- **Title:** "Server Access Request"
- **Fields:**
  - **Server Name** (Textbox for entering server details)
  - **Server IP Address** (Textbox for entering the server's IP)
  - **Access Justification** (Textarea for explaining why the server needs access)
  - **Submit Button:** "Submit Server Request"

---

### **6. Dynamic Visibility with JavaScript**
- **Script ensures that only one form is visible at a time** depending on user selection.
- **Initially, both forms are hidden** until an option is chosen.

---

### **7. Styling & Layout Adjustments**
- **Forms and inputs are fully contained within the request form container** to ensure a neat and organized structure.
- **Styling ensures consistency**:
  - Rounded input fields
  - Padding and margins for spacing
  - Background colors for readability
  - Buttons styled with clear call-to-action colors
