### **Updated Breakdown of the Admin Dashboard**  

The **Admin Dashboard** provides an **overview and management tools** for administrators to **monitor access requests, approvals, user roles, and security logs**.

---

### **1. Sidebar Navigation**  
- **Portal Logo & Title:** Displays "Self-Service Portal."  
- **Navigation Menu:**  
  - Home  
  - Request Access  
  - Approval Status  
  - Help/FAQs  
  - **Admin Dashboard (Current Page Highlighted)**  

---

### **2. Header Section**  
- **Title:** "Admin Dashboard"  
- **Brief Description:** Provides an overview of pending requests, user management, and system analytics.  
- **User Profile Menu:** (Top-right, includes settings, logout, and dark mode toggle)  
- **Notifications Icon:** (Bell icon for pending approvals and urgent updates)  

---

### **3. Dashboard Overview & Analytics Section**  
- **Summary Cards for Quick Insights:**  
  - **Total Requests Submitted:** (Displays count)  
  - **Pending Approvals:** (Displays count)  
  - **Approved Requests:** (Displays count)  
  - **Rejected Requests:** (Displays count)  
- **Graphical Reports & Charts:** (Placeholder for visualization)  
  - **Approval Trends Over Time** (Line Chart)

### **4. Pending Requests Management Section**  
- **Search & Filter Panel:**  
  - Search requests by **Request ID, URL, Requester Name**  
  - Filter by **Status (Pending, Approved, Rejected), Request Type, Date Range**  

- **Table Displaying Pending Requests:**  
  - **Columns:**  
    - Request ID  
    - Requested URL  
    - Requester  
    - Submission Date  
    - Current Approval Stage  
    - **Actions Column:**  
      - ✔ **Approve** Button  
      - ✖ **Reject** Button  

---

### **5. User Management Section**  
- **Admin Tools to Manage Users & Roles**  
- **Search & Filter Users by:**  
  - Username, Email, Role (User, Approver, Admin)  
- **User Actions:**  
  - **Role Selection Dropdown:** Admins can assign roles (User, Approver, Admin)  
  - **Automatically Updates Role in Database**  

---

### **6. Audit Logs Section**  
- **Tracks Important Actions for Security & Compliance:**  
  - Request approvals/rejections  
  - User role changes

- **Table Displaying Logs:**  
  - **Columns:**
