### **Audit Logs Page - Breakdown of Sections**  

The **Audit Logs Page** provides a **detailed record of system activities, user actions, and approval processes** for security and compliance tracking.

---

### **1. Sidebar Navigation**  
- **Portal Logo & Title:** Displays "Self-Service Portal."  
- **Navigation Menu:**  
  - Home  
  - Request Access  
  - Approval Status  
  - Help/FAQs  
  - Admin Dashboard  
  - Dashboard Analytics  
  - Approval Certificate  
  - **Audit Logs (Current Page Highlighted)**  

---

### **2. Header Section**  
- **Title:** "Audit Logs"  
- **Brief Description:** Displays a **chronological record of all system activities**, including approvals, rejections, role changes, and security-related events.  
- **User Profile Menu:** (Top-right, includes settings, logout, and dark mode toggle)  

---

### **3. Search & Filter Panel**  
- **Allows Admins to Filter Logs By:**  
  - **Search Bar:** Search logs by **User, Request ID, or Action Type**  
  - **Filters:**  
    - **Action Type:** Approvals, Rejections, Role Changes, Login Attempts  
    - **User Role:** Admin, Approver, Requester  
    - **Date Range Selector:** Select a time frame for audit log searches  

---

### **4. Audit Log Table Section**  
- **Displays a Chronological List of Events**  
  - **Columns:**  
    - **Timestamp:** When the action occurred  
    - **User:** The individual responsible for the action  
    - **Action:** The specific event (e.g., "Approved Request #12345")  
    - **Request ID:** Reference to the related request  
    - **Details:** Additional information about the action  

- **Example Logs:**  
  | Timestamp       | User          | Action              | Request ID | Details                   |  
  |---------------|--------------|---------------------|------------|--------------------------|  
  | 02/02/2024 10:30 AM | AdminUser    | Approved Request  | 12345      | Request approved by Admin |  
  | 02/02/2024 09:45 AM | John Doe     | Submitted Request | 12346      | Requested access to URL   |  
  | 01/02/2024 05:15 PM | SecurityTeam | Rejected Request  | 12344      | Security risk identified  |  
  | 01/02/2024 03:30 PM | System       | User Login        | —          | Login success (AdminUser) |  

- **Pagination for Large Log Data Sets**  

---

### **5. Export & Reporting Section**  
- **Download Audit Logs In:**  
  - **CSV**  
  - **PDF**  
  - **Excel**  

- **Custom Report Generation:**  
  - Allows admins to **select specific time periods and log types** for exporting.  

---

### **6. Footer Section**  
- **Company Information**  
- **Support & Contact Links**  
- **Privacy Policy & Terms of Service**  

---

### **Dynamic Features**  
- **Real-Time Log Updates:** New activities appear dynamically.  
- **Security-Focused Audit Trail:** Ensures compliance by tracking every critical action.  
- **Role-Based Access:** Only authorized personnel can view logs.
