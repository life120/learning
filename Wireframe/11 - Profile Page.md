### **Profile Page - Breakdown of Sections**  

The **Profile Page** allows users to manage their personal details, security settings, and preferences.

---

### **1. Sidebar Navigation**  
- **Portal Logo & Title:** Displays "Self-Service Portal."  
- **Navigation Menu:**  
  - Home  
  - Request Access  
  - Approval Status  
  - Help/FAQs  
  - Admin Dashboard  
  - Dashboard Analytics  
  - Approval Certificate  
  - Audit Logs  
  - **Profile (Current Page Highlighted)**  

---

### **2. Header Section**  
- **Title:** "User Profile"  
- **Brief Description:** Allows users to manage their account details and security settings.  
- **User Profile Icon:** Displays the user’s profile picture (or initials if not set).  

---

### **3. Profile Information Section**  
- **Displays User Details:**  
  - **Full Name**  
  - **Email Address**  
  - **Username**  
  - **Department**  
  - **Role (User, Approver, Admin, etc.)**  
- **Edit Button:** Allows users to update profile details if permitted.  

---

### **4. Security & Authentication Settings Section**  
- **Change Password Option:**  
  - Fields for **Current Password, New Password, Confirm New Password**.  
  - Strength meter to indicate password security.  
- **Enable Two-Factor Authentication (2FA):**  
  - Toggle switch to enable or disable 2FA.  
  - Displays QR code or link to set up authentication via mobile apps (e.g., Google Authenticator).  

---

### **5. Notification Preferences Section**  
- **Manage Email & In-App Notifications:**  
  - Toggle options for:  
    - Approval request updates  
    - Security alerts  
    - System updates  
- **Save Preferences Button:** To apply notification changes.  

---

### **6. Recent Activity Section**  
- **Logs User’s Recent Actions:**  
  - Displays **last login timestamp**.  
  - Shows **last 5 activities** (e.g., "Requested access to example.com", "Changed password", "Approved request #12345").  
- **View More Activity Link:** Redirects to the Audit Logs page for full history.  

---

### **7. Account Management Section**  
- **Deactivate Account Button:**  
  - Users can **request deactivation** if they no longer need portal access.  
  - Requires confirmation before proceeding.  

---

### **8. Footer Section**  
- **Company Support & Contact Links**  
- **Privacy Policy & Terms of Service**  

---

### **Dynamic Features**  
- **Real-Time Profile Updates:** Changes reflect immediately after saving.  
- **Dark Mode Support:** Matches system-wide settings.  
- **Security Alerts for Critical Changes:** Sends an email if password or 2FA is modified.
